# Практика занятий 23 и 24

## Занятие 23. Фрагмент урока

Подготовьте сценарий фрагмента по листу 23_scenariy_fragmenta.md на 15–20 минут. Проведите фрагмент для коллег. Коллеги выполняют задание как ученики и заполняют форму 23_forma_obratnoy_svyazi.md. Запишите одну вещь, которую вы измените после обратной связи.

Результат: доработанный сценарий, файлы для учеников и заполненные формы обратной связи.

## Занятие 24. Финальный пакет проекта

Соберите пакет по чек-листу 24_paket_proekta_chek-list.md. Проверьте его на чистой папке. Пройдите демонстрацию: участники запускают проект, меняют один параметр и объясняют результат. Задайте два вопроса из листа 24_voprosy_uchastnikam.md.

Результат: пакет проекта с README, заполненный чек-лист и ответы участников на два вопроса.
