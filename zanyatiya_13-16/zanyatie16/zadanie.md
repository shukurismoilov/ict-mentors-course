# Занятие 16. Мини-викторина

Откройте `index.html` и реализуйте игру в `script.js`.

1. Создайте массив из трёх вопросов. Для каждого сохраните текст `q`, массив `options` и индекс правильного ответа `answer`.
2. Создайте переменные состояния: индекс текущего вопроса, счёт, признак уже данного ответа и выбранный вариант.
3. Получите элементы страницы по `id`. Напишите `showQuestion()`: покажите номер и текст вопроса, создайте варианты ответов с радио-кнопками, очистите обратную связь и включите нужные кнопки.
4. Напишите `checkAnswer()`. Если вариант не выбран, попросите выбрать его. После проверки начислите балл только один раз и покажите, верен ли ответ.
5. Напишите `nextQuestion()`. После последнего вопроса вызовите `showResult()`, а не пытайтесь показать отсутствующий элемент массива.
6. В `showResult()` покажите итог «Ваш результат: N из 3» и отключите кнопки.
7. Проверьте: ответ без выбора, правильный и неправильный ответы, повторное нажатие, переход после последнего вопроса и результат 0 из 3.

**Результат:** викторина с тремя вопросами, обратной связью и итоговым счётом.
