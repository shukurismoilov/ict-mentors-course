# Занятие 15. Генератор карточек

Откройте `index.html` и заполните `script.js`. На странице подготовлены поле поиска и контейнер для карточек.

1. Создайте массив `cards` из пяти объектов. У каждого объекта должны быть свойства `title` и `text`.
2. Найдите элементы `container` и `filter` через `document.getElementById()`.
3. Создайте функцию `render(list)`: сначала очистите контейнер, затем для каждого объекта создайте карточку с заголовком `h3` и абзацем `p`.
4. Добавляйте заголовок и описание через `textContent`, а готовую карточку — через `appendChild()`.
5. Вызовите `render(cards)`, чтобы показать все карточки при загрузке.
6. Добавьте обработчик события `input` для поля поиска. Приведите введённый текст и названия к нижнему регистру и отфильтруйте карточки с помощью `filter()` и `includes()`.
7. Проверьте поиск по `css`, поиск по слову, которого нет, и пустое поле.

**Результат:** пять карточек и фильтр, который ищет по названию без учёта регистра.

**Подумайте:** зачем очищать контейнер перед повторной отрисовкой и почему для текста карточек лучше использовать `textContent`, а не `innerHTML`?
