### Дарси 13. Миқдорҳо ва ҳисобкунӣ

**Ҳисобкунак дар консоль ва дар саҳифа**

**Ҳадафи дарс**
- Консоли браузерро кушоед ва аввалин фармонҳоро иҷро кунед.
- Миқдорҳоро бо `let` ва `const` эълон кунед.
- Нарх ё холро ҳисоб карда, натиҷаро ба саҳифа баровед.

**Консоли браузер**
- F12 → ҷадвали «Консоль» (Console).
- `console.log(арзиш)` арзишро ба консоль мебарояд.
- Ворид кунед `2 + 2` ва Enter пахш кунед: консоль натиҷаи 4-ро нишон медиҳад.
- Консоль барои санҷиш, ҳангоми навиштани код, муфид аст.

**Миқдорҳо ва арифметика**
- `let price = 1200;` — миқдоре, ки қиматашро метавон иваз кард.
- `const rate = 10;` — доимӣ, қиматашро иваз кардан мумкин нест; кӯшиш хатои TypeError медиҳад.
- `total = price * count;` ва `discount = total * 10 / 100;`
- Тартиби амалҳо ҳамон тавр аст, ки дар математика.

**Унсурҳои саҳифа**
- `document.getElementById("price")` унсурро бо id меёбад.
- `.value` — арзиши майдони воридкунӣ; `.textContent` — матни унсур, ки онро дигар кардан мумкин аст.
- Арзиши майдон ҳамчун сатр меояд. `Number(сатр)` онро ба рақам табдил медиҳад.

**Амалӣ 13**
1. Саҳифаи ҳисобкунакро кушоед ва F12-ро пахш кунед.
2. Супоришҳоро дар консоль иҷро кунед: миқдорҳо, `total`, `const`, ҳисоби тахфиф.
3. script.js-ро пур кунед: тугмаи «Ҳисоб кардан» бояд ҷамъи бо тахфиф баробарро ба унсури `out` барорад.

**Натиҷа:** ҳисобкунак дар саҳифа ва сабтҳои консоль.

**Хатогиҳои маъмул 13**
- Ҳеҷ чиз рух намедиҳад: script.js пайваст нест ё холӣ аст.
- Натиҷаи «1200 3» ба ҷои 3600: арзишҳо ҳамчун сатр пайваст мешаванд. `Number()` истифода баред.
- Assignment to constant: миқдор бо `const` эълон шудааст.

### Дарси 14. Шартҳо ва коркунандаи пахш

**Санҷиши ҷавоб: тугма ва шарт**

**Коркунандаи пахш (обработчик)**
- `button.addEventListener("click", () => { ... });`
- Коди дохили функсия ҳар бор ҳангоми пахш иҷро мешавад, на фавран.
- `() => { }` — шакли кӯтоҳи функсия.

**Шарт**
- `if (шарт) { ... } else if (шарт) { ... } else { ... }`
- Шарт натиҷаи `true` ё `false` медиҳад. `===` арзиш ва навъро муқоиса мекунад.
- Аввалин шохаи мувофиқ иҷро мешавад, қолганҳо гузаронида мешаванд.

**Кор бо майдони воридкунӣ**
- `input.value` — матне, ки корбар ворид кардааст.
- `trim()` фосилаҳои холиро аз канор мезудояд.
- `Number("")` натиҷаи 0 медиҳад, пас холигиро аввал тафтиш кунед.

**Амалӣ 14**
1. Санҷиши ҷавобро кушоед. script.js-ро пур кунед: коркунандаи click, хондани майдон, trim.
2. Се шохаи шарт: холӣ, дуруст (42), нодуруст.
3. Саволу ҷавоби худро иваз кунед.

**Натиҷа:** санҷиши ҷавоб бо се паём.

**Хатогиҳои маъмул 14**
- Паём иваз намешавад: id-ро дар getElementById санҷед.
- Муқоиса кор намекунад: майдон сатр бармегардонад, бо "42" муқоиса кунед ё `Number()` истифода баред.
- Unexpected token: қавс ё иқтибос партофта шудааст.
- Ворӯди холӣ нодуруст ҳисоб мешавад: холиро дар шохаи аввал тафтиш кунед.

### Дарси 15. Генератори кортҳо

**Массивҳо, даврҳо ва сохтани унсурҳо**

**Ҳадафи дарс**
- Маълумотро дар массиви объектҳо нигоҳ доред.
- Массивро бо давр тай кунед ва барои ҳар объект унсур эҷод кунед.
- Кортҳоро аз маълумот дар саҳифа бисозед.

**Массиви объектҳо**
- `cards.length` — шумораи унсурҳо; `cards[0]` — унсури аввал.
- Дар консоль `cards[1].title` CSS-ро нишон медиҳад.

**Даврҳо**
- `for (const card of cards) { ... }` — тай кардан бо арзишҳо.
- `cards.forEach(card => { ... })` — ҳамон кор, ҳамчун усул.
- Давр лозим аст, то барои ҳар унсур код нанависед.

**Сохтани унсурҳо**
- `document.createElement("div")` — унсури нав.
- `div.textContent = card.title;` — дохил кардани матни бехатар.
- `container.appendChild(div);` — илова ба саҳифа.
- `innerHTML` бо маълумоти корбар хатарнок аст: `textContent` истифода баред.

**Амалӣ 15**
1. Массиви панҷ объектро бо сарлавҳа ва матн эҷод кунед.
2. Бо давр барои ҳар объект корт созед ва ба контейнер илова кунед.
3. Филтр илова кунед: танҳо кортҳоеро нишон диҳед, ки калимаи дар title ҷустуҷӯшуда доранд.

**Натиҷа:** генератори кортҳо, ки аз маълумот сохта мешавад.

**Хатогиҳои маъмул 15**
- Кортҳо пайдо намешаванд: контейнер бо id-и дуруст дар HTML ёфт нашуд.
- `undefined` зоҳир мешавад: майдони мавҷуднабуда, масалан `card.tittle` ба ҷои `card.title`.
- Кортҳо такрор мешаванд: давр ду маротиба иҷро шудааст ё унсурҳо дар дохили давр бо такрор илова шудаанд.

### Дарси 16. Викторинаи хурд

**Саволҳо, холҳо ва бозгашти ахборот**

**Ҳадафи дарс**
- Викторинаро аз чанд савол созед.
- Холҳоро ҳисоб кунед ва баъд аз ҳар ҷавоб бозгашти ахборот нишон диҳед.
- Ҳолатҳои марзиро санҷед: саволи охирин, интихоби холӣ, пахши такрорӣ.

**Сохтори викторина**
- `const questions = [{ q: "...", options: [...], answer: 1 }];`
- `let current = 0;` — индекси саволи ҷорӣ.
- `let score = 0;` — холҳои ҷамъшуда.
- Пас аз саволи охирин экрани натиҷа нишон дода мешавад.

**Мантиқи ҷавоб**
- Корбар вариантро интихоб мекунад: индекси онро нигоҳ медорем.
- Бо `answer` муқоиса мекунем: агар мувофиқ бошад, `score += 1`.
- Бозгашти ахборот: «Дуруст» ё «Нодуруст, ҷавоби дуруст…».
- Ба саволи навбатӣ мегузарем: `current += 1`.

**Ҳолатҳои марзӣ**
- Пахши «Баъдӣ» бе интихоб: паём нишон дода шавад.
- Пахши такрории «Ҷавоб додан»: холҳо ду маротиба афзун намешаванд.
- Саволи охирин: пас аз он натиҷа нишон дода мешавад, на саволи нав.
- Холи сифр: натиҷаи 0 аз N, бе хато.

**Амалӣ 16**
1. Массиви се саволро бо чор вариант эҷод кунед.
2. Саволи аввалро нишон диҳед ва интихоби ҷавобро коркард кунед.
3. Ҳисоби холҳо, бозгашти ахборот ва гузариш ба саволи навбатиро илова кунед.
4. Ҳолатҳои марзиро аз слайд санҷед.

**Натиҷа:** викторинаи анҷомёфта дар HTML, CSS ва JavaScript.

**Хатогиҳои маъмул 16**
- Ҳисоб ҳар пахш афзун мешавад: байраки «ҷавоб дода шуд» илова кунед.
- Хатои пас аз саволи охирин: индекс аз массив берун рафтааст. `current < questions.length`-ро тафтиш кунед.
- Тугма блок намешавад: тугмаро бо `disabled` хомӯш кунед.

## Қисм 2. Кодҳо бо шарҳҳо ва матни тоҷикӣ

Номҳои `id`, `const`, `let`, функсияҳо ва методҳо дар англисӣ мемонанд, то код дуруст кор кунад. Шарҳҳо ва матнҳое, ки корбар мебинад, ба тоҷикӣ иваз шудаанд.

### Дарси 13. script.js

```js
// Унсурҳоро аз саҳифа мегирем
const priceInput = document.getElementById("price");   // майдони нарх
const countInput = document.getElementById("count");   // майдони шумора
const button = document.getElementById("calc");        // тугмаи «Ҳисоб кардан»
const out = document.getElementById("out");            // ҷои натиҷа

// Ҳангоми пахши тугма ҳисоб мекунем
button.addEventListener("click", () => {
  const price = Number(priceInput.value);              // сатрро ба рақам табдил медиҳем
  const count = Number(countInput.value);
  const total = price * count;                         // ҷамъи умумӣ
  const withDiscount = total - (total * 10) / 100;     // бо тахфифи 10%
  console.log("Ҷамъ:", total);                         // нишон дар консоль
  out.textContent = `Ҷамъ: ${total} сомонӣ, бо тахфиф 10%: ${withDiscount} сомонӣ`;
});
```

**Санҷиш:** пас аз пахши тугма дар абзац «Ҷамъ: 3600 сомонӣ, бо тахфиф 10%: 3240 сомонӣ» пайдо мешавад.

*Ёддошт:* арзи пул дар ин мисол бо «сомонӣ» нишон дода шудааст, зеро курс барои тоҷикистониҳо аст. Агар бо рубл кор кунед, сатри матнро иваз кунед.

### Дарси 14. script.js

```js
// Унсурҳоро меёбем
const input = document.getElementById("answer");   // майдони ҷавоб
const button = document.getElementById("check");   // тугмаи «Санҷидан»
const message = document.getElementById("message"); // ҷои паём

// Ҳангоми пахши тугма ҷавобро санҷем
button.addEventListener("click", () => {
  const value = input.value.trim();                // фосилаҳои иловагиро мезудоем
  if (value === "") {
    message.textContent = "Ҷавобро ворид кунед";   // майдон холӣ аст
  } else if (Number(value) === 42) {
    message.textContent = "Дуруст!";               // ҷавоби дуруст
  } else {
    message.textContent = "Нодуруст, дубора кӯшиш кунед";
  }
});
```

**Санҷиш:** майдони холӣ → «Ҷавобро ворид кунед». 42 → «Дуруст!». Арзиши дигар → «Нодуруст, дубора кӯшиш кунед».

### Дарси 15. script.js

```js
// Маълумот: массиви кортҳо
const cards = [
  { title: "HTML", text: "Сохтори саҳифа" },
  { title: "CSS", text: "Зебоӣ ва тарҳ" },
  { title: "JavaScript", text: "Рафтори саҳифа" },
  { title: "Python", text: "Барнома ва маълумот" },
  { title: "ИИ", text: "Ёрдамчӣ дар кор" }
];

const container = document.getElementById("container"); // ҷои кортҳо
const filterInput = document.getElementById("filter");  // майдони филтр

// Функсия: кортҳоро дар саҳифа месозад
function render(list) {
  container.textContent = "";                      // ҳамаи кортҳои пешинро тоза мекунем
  for (const card of list) {                       // аз ҳар объект мегузарем
    const div = document.createElement("div");
    const h = document.createElement("h3");
    const p = document.createElement("p");
    h.textContent = card.title;
    p.textContent = card.text;
    div.appendChild(h);
    div.appendChild(p);
    container.appendChild(div);
  }
}

render(cards);   // аввалин бор ҳамаи кортҳоро нишон медиҳем

// Ҳангоми навиштани матн филтр мекунем
filterInput.addEventListener("input", (e) => {
  const word = e.target.value.trim().toLowerCase();
  render(cards.filter((card) => card.title.toLowerCase().includes(word)));
});
```

**Санҷиш:** вақте «css» ворид мекунед, як корт мемонад. Майдонро холӣ кунед — ҳамаи панҷ корт бармегарданд.

### Дарси 16. script.js

```js
// Саволҳо: ҳар савол матн, вариантҳо ва индекси ҷавоби дуруст дорад
const questions = [
  { q: "Кадом тег сарлавҳаи h1-ро месозад?", options: ["<p>", "<h1>", "<div>"], answer: 1 },
  { q: "Кадом хосият рангӣ матнро иваз мекунад?", options: ["background", "color", "margin"], answer: 1 },
  { q: "Кадом метод коркунандаи ҳодисаро илова мекунад?", options: ["addEventListener", "getElementById", "createElement"], answer: 0 }
];

// Ҳолати барнома
let current = 0;        // индекси савол
let score = 0;          // холҳо
let answered = false;   // оё ҷавоб дода шуд?
let selected = null;    // кадом вариант интихоб шудааст

// Унсурҳо
const questionEl = document.getElementById("question");
const optionsEl = document.getElementById("options");
const answerBtn = document.getElementById("answerBtn");
const nextBtn = document.getElementById("nextBtn");
const feedbackEl = document.getElementById("feedback");
const progressEl = document.getElementById("progress");
const resultEl = document.getElementById("result");

// Нишон додани савол
function showQuestion() {
  const item = questions[current];
  answered = false;
  selected = null;

  progressEl.textContent = `Савол ${current + 1} аз ${questions.length}`;
  questionEl.textContent = item.q;
  optionsEl.textContent = "";

  item.options.forEach((text, index) => {
    const label = document.createElement("label");
    const radio = document.createElement("input");
    radio.type = "radio";
    radio.name = "option";
    radio.addEventListener("change", () => {
      selected = index;                            // вариантро дар хотира нигоҳ медорем
    });
    label.appendChild(radio);
    label.append(" " + text);
    optionsEl.appendChild(label);
  });

  feedbackEl.textContent = "";
  answerBtn.disabled = false;
  nextBtn.disabled = true;
}

// Санҷидани ҷавоб
function checkAnswer() {
  if (answered) return;                            // дубора ҷавоб додан мумкин нест

  if (selected === null) {
    feedbackEl.textContent = "Вариантро интихоб кунед.";
    return;
  }

  answered = true;
  const item = questions[current];

  if (selected === item.answer) {
    score += 1;
    feedbackEl.textContent = "Дуруст!";
  } else {
    feedbackEl.textContent = `Нодуруст. Ҷавоби дуруст: ${item.options[item.answer]}`;
  }

  answerBtn.disabled = true;
  nextBtn.disabled = false;
}

// Гузариш ба саволи навбатӣ ё натиҷа
function nextQuestion() {
  if (!answered) return;
  current += 1;

  if (current < questions.length) {
    showQuestion();
  } else {
    showResult();
  }
}

// Экрани натиҷа
function showResult() {
  questionEl.textContent = "Викторина анҷом ёфт";
  optionsEl.textContent = "";
  feedbackEl.textContent = "";
  progressEl.textContent = "";
  resultEl.textContent = `Натиҷаи шумо: ${score} аз ${questions.length}`;
  answerBtn.disabled = true;
  nextBtn.disabled = true;
}

answerBtn.addEventListener("click", checkAnswer);
nextBtn.addEventListener("click", nextQuestion);

showQuestion();
```

**Санҷиш:**
1. Пахши «Ҷавоб додан» бе интихоб → «Вариантро интихоб кунед».
2. Пахши такрорӣ пас аз ҷавоб ҳисобро тағйир намедиҳад.
3. Пас аз саволи охирин: «Натиҷаи шумо: N аз 3».
4. Ҳама ҷавобҳои нодуруст → «Натиҷаи шумо: 0 аз 3», бе хато.
