## Қисми 2. Шарҳҳои кодҳо ба тоҷикӣ

```python
# Занятие 17 (дарси 17): ҳисобкунаки консолӣ
print("Ҳисобкунаки консолӣ")
price = float(input("Нархи мол: "))          # нарх — адади касрӣ
count = int(input("Шумора: "))               # шумора — адади бутун
discount = float(input("Тахфиф, %: "))

total = price * count                        # ҷамъи умумӣ
final = total - total * discount / 100       # бо тахфиф

print("Ҷамъ:", total)
print("Бо тахфиф:", round(final, 2))         # round — то 2 рақами поси вергул
```

```python
# Дарси 18: функсия бо санҷиши ворид
def ask_choice(prompt, count):
    while True:                              # то ворид шудани ҷавоби дуруст такрор
        text = input(prompt)
        try:
            choice = int(text)               # matnро ба адад табдил медиҳем
        except ValueError:
            print("Хато: лутфан раками бутун ворид кунед.")
            continue                         # ба аввали давр бармегардем
        if 1 <= choice <= count:
            return choice                    # ҷавоби дуруст — аз функсия бармегардем
        print(f"Хато: адади аз 1 то {count} ворид кунед.")
```

```python
# Дарси 19: хондани CSV бо санҷиши сатрҳо
import csv

def load(path):
    rows = []
    with open(path, encoding="utf-8") as f:
        for line_no, row in enumerate(csv.DictReader(f), start=2):
            try:
                rows.append({"name": row["имя"], "score": int(row["балл"])})
            except (KeyError, ValueError):
                print(f"Сатри {line_no}: маълумот нодуруст аст, партофта шуд.")
    return rows
```

*Ёддошт:* номи калидҳо ("имя", "балл") ба забони файли CSV мувофиқ аст ва бояд дар файл ҳамин тавр бошанд. Агар файли CSV бо тоҷикӣ сохта шавад, калидҳоро дар код иваз кунед.
