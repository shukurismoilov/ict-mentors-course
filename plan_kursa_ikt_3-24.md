# Практический курс ИКТ для наставников: занятия 3–24

Каждое занятие строится как последовательность шагов: участники наблюдают короткий показ на экране, выполняют задание на своих компьютерах, меняют результат, проверяют его и объясняют партнёру. Презентация служит сценарием действий. Все материалы, ссылки и стартовые файлы раздаются на самом занятии. Работа ведётся на компьютерах с Windows, терминал — «Командная строка» (cmd).

| № | Практика во время занятия | Готовый результат | Что подготовить преподавателю |
|---|---|---|---|
| 3 | Разобрать путь от клавиши к изображению; найти CPU, RAM, накопитель и ОС в сведениях своего ПК; сравнить показатель памяти до и после открытия вкладок | Паспорт компьютера и объяснение наблюдения | HTML-страница для лаборатории занятия 3; проверить путь «Параметры → Система → О системе» на Windows |
| 4 | Создать дерево папок, переместить, переименовать, найти и заархивировать файлы; посмотреть запущенные приложения | Папка проекта и архив | Папка с 6 разными файлами для раздачи; карточка действий для Windows |
| 5 | Найти локальный IP, проверить соединение, открыть сайт и проследить DNS → IP → запрос → ответ | Схема своей сети с измерениями | Выбрать тестовый сайт; проверить `ipconfig` и `ping` в cmd |
| 6 | Открыть «Командную строку», перейти в папку, создать файл, прочитать его и повторить через историю команд | Журнал команд с результатами | Мини-шпаргалка `cd`, `dir`, `mkdir`, `echo`, `type` для раздачи |
