# Занятие 21. Настройка рабочего пространства ИИ

## Шаблон контекста (без личных данных)

Не вставляйте в запрос имена, адреса, номера телефонов, пароли, данные учеников и любые персональные сведения. Замените их на обобщённые описания, например «ученик 10 лет» вместо имени.

```
Роль: ты помогаешь преподавателю информатики подготовить практический урок.
Аудитория: взрослые участники курса, начинающие программисты.
Язык ответа: русский.
Формат ответа: список шагов с короткими пояснениями, без лишнего текста.
Длина: не больше 300 слов.
Ограничения: не придумывай факты; если не уверен, так и напиши.
Задача: [здесь опишите задачу]
```

## Сохранённая инструкция

Если сервис позволяет сохранять инструкцию в настройках, сохраните шаблон выше. Если нет, вставляйте его в начало каждого нового диалога.

## Три проверочные задачи

1. Объясните, что такое переменная, для новичка в пяти шагах.
2. Составьте план занятия на 20 минут по теме «условия в программировании».
3. Напишите короткое объявление о наборе на курс, не больше 60 слов.

Для каждой задачи запустите запрос дважды: сначала без шаблона, потом с шаблоном. Сравните ответы.
