# Занятие 12. CSS и адаптивность

Откройте папку zanyatie12 в VS Code. Страница start.html уже подключает файл style.css, но сам файл пуст.

1. Задайте для body шрифт Arial и фон #f5f7fa. Проверьте, что страница изменилась после сохранения и обновления F5.
2. Сделайте заголовок h1 цветом #1f3a5f и добавьте отступ снизу 16px.
3. Ограничьте ширину основного содержимого: main с max-width 720px, margin 0 auto и padding 16px.
4. Оформите таблицу: border-collapse: collapse, границы у th и td, фон заголовков таблицы #e8eef6.
5. Сделайте кнопку отправки формы цветом фона #1f3a5f, белым текстом и отступом 10px 20px.
6. Добавьте медиазапрос @media (max-width: 600px), где таблица и форма занимают всю ширину, а отступы уменьшаются. Уменьшите окно браузера в F12 через режим адаптивного просмотра и проверьте результат.
7. Используйте display: grid для блока с тремя способами защиты: сделайте его карточками. Для этого оберните таблицу в div, если это нужно, или опишите сетку письменно.

Результат: оформленная страница, адаптивная при ширине 600 пикселей, и письменный ответ на вопрос, что делает max-width.
